Pooling kernel lab ▾ min/max/avg · gaussian · laplacian
Upload an image to enable the before/after comparator.
Kernel matrix:
BEFORE AFTER

Drag the cyan divider to sweep between the original image and the kernel output.

What this teaches: Max pooling keeps the brightest pixel in each window (edge-preserving downscale), min keeps the darkest, and average blends toward a blur while downscaling. Gaussian smoothing trades exactness for softness — its weights fall off from the window center and sigma grows with the intensity slider. A Laplacian kernel subtracts each pixel from its neighborhood so strong local differences (edges) light up — the same sharpen kernel many photo editors ship.

What this teaches: Modern Vision-Language Models (Qwen2.5-VL, CLIP-style encoders) never see images directly in their spirit — each word becomes a high-dimensional token vector, and the attention mechanism asks every image patch “how relevant are you to this word?” This studio inverts that process: it decomposes your prompt into tokens (striker → sport, goalkeeper → person/moving, referee → person/rules), assigns each a spatial Gaussian region in the 2D latent plane, and rolls a die seeded by the token hash to decide which regions light up — exactly how a diffusion model decides where to paint a midfield line versus a flying ball. The inverse problem is the deep one: generating images from feature activations (here) versus classifying images into tokens (the forward pass). Both share the same latent space; generation just walks it backward. Hover the heatmap to see which patch attended to which token.
