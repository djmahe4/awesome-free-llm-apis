# v1.1.2 fixes register

Source: four read-only audits of `release/v1.1.1` (harness, browser, cyber, coding/skills/memory).
**Status of every item: reported by an audit agent, not yet independently verified.** Reproduce with a failing
test before changing code; that test is the acceptance criterion for the item.

Workflow: one small branch per slice, cut from `v1.1.2` (use `git worktree add ../wt-<slice> -b <branch> v1.1.2`),
test first (red), fix (green), merge back into `v1.1.2`. Paths are relative to `mcp-server/`.

Severity: **H** wrong result or damage today, **M** wrong in edge cases or unsafe default, **L** hygiene.

### TDD plan for coding_agents (write these red first)

Test file: `tests/coding-agents-patchgen-robust.test.ts` (truncation tests in `tests/local-llm-patch.test.ts`).
Research basis: Aider edit formats and flexible patching (https://aider.chat/docs/unified-diffs.html: flexible patching off = 9x more edit
errors), Agentless localize/repair/validate (https://arxiv.org/abs/2407.01489), SWE-agent edit-time lint gate
(https://arxiv.org/abs/2405.15793), test-overfitting risks (https://arxiv.org/abs/2511.16858, https://arxiv.org/abs/2312.04687),
Ollama API (https://github.com/ollama/ollama/blob/main/docs/api.md). Keep text SEARCH/REPLACE blocks (JSON-wrapped code is worse per Aider);
use a JSON schema only for a tiny "pick a symbol" step.

1. **zero-score window fallback**: 400-line TS fixture; instruction "add a method zzzNew to class TargetClass".
   (a) no term hits anywhere: window must not be lines 0..N by accident (return a `scored:false` signal, pipeline uses a symbol outline);
   (b) instruction names `TargetClass`: window contains `class TargetClass` and its closing brace (boost `class|function|interface X` lines).
2. **empty SEARCH**: default stays rejected with an explanatory failure; `{allowAppend:true}` appends at EOF; empty SEARCH on an empty file is accepted (create case).
3. **anchor retention**: `blockDropsAnchor(search, replace)` true when REPLACE lacks the trimmed SEARCH lines (unless rename/delete); additive apply fails with `anchor not retained`, content unchanged.
4. **num_ctx truncation**: mocked fetch `prompt_eval_count >= numCtx` gives `truncated:true` and `localLlmPatch` fails with a truncation error; `done_reason:'length'` plus an unterminated REPLACE reports "output truncated".
5. **multi-block parsing**: 3 blocks with prose between, one inside a fenced diff, one CRLF, one unterminated: 2 complete blocks, `incomplete:1`, order preserved; sequential dependency between blocks; failure of one block writes none (atomic).
6. **hallucinated replacement**: unrelated 20-line script vs a 364-line class is flagged; `// ... rest of code` / ellipsis in REPLACE rejected on the SEARCH/REPLACE path too (today the gate runs only on full-file paths); a valid additive edit is not flagged.
7. **extra gates (after the six)**: retry-with-feedback (failure text plus nearest real lines in the second prompt, max 3 attempts); fuzzy tier (unique match, similarity >= 0.9); patcher cannot write `*.test.*` files on code tasks (tests stay read-only).

Implementation order (each step turns its tests green):
1. Pass `numCtx`, `maxTokens`, `temperature:0` from `localLlmPatch`; add truncation detection (test 4). Cheapest and removes silent corruption.
2. Window fallback with symbol weighting (test 1); tree-sitter later.
3. Parser incomplete-block flag and append mode (tests 5, 2).
4. Anchor retention (test 3).
5. Hallucination/ellipsis gate on the SEARCH/REPLACE path (test 6).
6. Retry-with-feedback over a deterministic gate chain: parse, apply, ts-morph error delta (`searchReplaceRegressesTsErrors`), project tests.
7. Fuzzy tier, then optional two-step localization.

7B prompt guidance: one full SEARCH/REPLACE few-shot, window of ~80-120 lines centred on the chosen symbol, one-sentence instruction, temperature 0, SEARCH limited to 1-3 anchor lines.

## Research findings for docs/plans/rev_tool.md (corrections the plan needs)

Recorded from web research on 2026-10-21; items marked "unverified" were not fetched.

**GGUF** (spec: https://raw.githubusercontent.com/ggml-org/ggml/master/docs/gguf.md)
- Header: `GGUF` magic, version u32 (3), tensor_count u64, metadata_kv_count u64, little-endian.
- Metadata type sizes: 0 u8, 1 i8, 2 u16, 3 i16, 4 u32, 5 i32, 6 f32, 7 bool(1), 8 string(8+len), 9 array(4+8+elements, walk them), 10 u64, 11 i64, 12 f64. The plan's parser treats 6/7 as ints and skips arrays by 12 bytes: wrong.
- Alignment `general.alignment` (default 32); data start is the aligned end of the tensor-info region.
- Use the official `gguf` package (MIT) instead of a hand parser. Quantized tensors cannot be written to safetensors without dequantizing: label output `dequantized approximation`.
- `reverse_training_data` returns hardcoded numbers (14.2, 0.042): remove. Replace with `probe_memorization` (real per-text perplexity / min-k% on user-supplied texts, or `not_available`). Weights alone cannot reveal training data.
- Path safety: resolve inside an allowlisted root, `.gguf` suffix + magic check, size and count caps, never use tensor names as paths.

**Audio** (https://github.com/facebookresearch/demucs, https://github.com/timsainb/noisereduce)
- Demucs is archived (2025-01-01), MIT: pin the version; CPU flag is `-d cpu` (the plan's `--device cpu` is unconfirmed); CPU time is about 1.5x track length so use a long timeout; ffmpeg required.
- The plan's spectral-gating formula is not noisereduce's algorithm; HPSS API unverified (docs link 404), drop HPSS until confirmed.
- Cache key: sha256(bytes) + model + version + flags; write to a temp dir then atomic rename; spawn with an args array, `shell:false`, timeouts, output caps.

**AnyAngle / 3D** (https://huggingface.co/lilylilith/QI_2.1_AnyAngle, https://github.com/VAST-AI-Research/TripoSplat)
- Models exist, but the full pipeline is no-go on CPU-only machines (7B DiT + 8B text encoder, about 16 GB at best); base model licence is the Qwen Research License (not clearly commercial-safe); the plan's pipeline class is the wrong one for Qwen-Image-2.1; several figures are unverifiable.
- Minimal honest scope: Depth-Anything-V2-Small (Apache-2.0, about 100 MB) pseudo-3D parallax in a Python subprocess; AnyAngle only as an opt-in GPU/remote mode with a licence warning.

**REA / MCP proxy** (https://registry.npmjs.org/rea-agents, https://raw.githubusercontent.com/morluto/rea/main/docs/mcp-contracts.md, MCP spec 2025-06-18)
- `rea-agents` is real (npm, MIT, 6.7.0 at time of research, repo `morluto/rea`); `npx -y rea-agents@<exact> mcp` is the documented form. It is very new and hype-driven with heavy dependencies (playwright-core, node-pty): supply-chain risk. Needs Node >=22.19 (not 23/25).
- Pin the exact version; better, install once into a private directory with a committed lockfile and `npm ci --ignore-scripts`, then run its `mcp` entry directly. Verify with `npm view rea-agents@<ver> scripts dependencies dist.integrity`.
- The plan's tool names (`analyze_binary_target`, `inspect_javascript_bundle`, `sanitize_and_inspect_traffic`) do not exist. Do not hardcode names: discover them with `tools/list` and allowlist from that. Real examples: `open_binary`, `binary_overview`, `analyze_function`, `inspect_artifact`, `analyze_javascript_application`, `get_evidence_bundle`, `list_unknowns`.
- The plan's "evidence contract" (observations/derivations/inferences/residual unknowns) is not REA's. REA uses Evidence records (`evidence_id`, `normalized_result`, `analysis_profile`, `coverage`, `limitations`) plus `list_unknowns`; it does not sanitize traffic, it tags results `_meta.provenance.untrusted_content: true`. The proxy must preserve that tag and treat all output as untrusted (prompt-injection-capable) data. Retained evidence refs only live on one MCP connection, so reuse one long-lived session.
- The 4 MiB cap applies to REA's updater commands only; MCP responses use `REA_MCP_MAX_RESPONSE_BYTES`. Enforce our own caps and timeouts.
- The plan's proxy skips the MCP handshake. Required order: `initialize` request, wait for the response, `notifications/initialized`, then `tools/list` / `tools/call`. Per-request timeout plus `notifications/cancelled`.
- Shutdown: close stdin, wait, SIGTERM, SIGKILL. Windows has no process groups: use `taskkill /pid N /T /F`; Unix: `detached` + `process.kill(-pid)`.
- Never expose `rea setup` (rewrites agent configs) or `rea mcp --http` (no auth/TLS). `analyze-javascript-application <path> --json` needs no native engine and is a simpler first provider.
