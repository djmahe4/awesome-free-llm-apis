# v1.1.2 research: papers, memory budgets and licences

Companion to `v1.1.2-fixes.md` and `rev_tool.md`. Gathered 2026-10-21 by agents that read arXiv HTML full text
(Method, Results, Implementation) rather than abstracts.

## How to read this document

- **Hard constraint:** peak GPU memory <= 6 GB VRAM, with a CPU-only fallback. Open-source, permissive licences preferred.
- **Reported** = a number taken from the paper or an official README. **Estimate** = the research agent's own inference; verify by measurement.
  Most papers report no inference VRAM. Wherever this table says "not reported", the paper does not say.
- Fetches were capped at about 100k characters, so appendices and limitation sections were often unread. Each such paper is marked.
- **Licences must be confirmed in the LICENSE file or model card before shipping.** Repo licences were mostly not checked.
  Several weights are trained on MUSDB or internal data and carry unclear (often non-commercial) terms.

Design implications (the first three are paper-backed, the rest are inference):

1. Do not depend on a <=7B model emitting correct SEARCH/REPLACE on big files. Ask for a whole function or small region and apply it programmatically.
2. Localize in code (AST/regex skeleton), give the model about 100 lines.
3. Gate every edit with a syntax or type check; at most 1-2 retries with the error text, because failures cascade.
4. Accept fuzzy matching (whitespace-normalized, anchor line) on SEARCH blocks.
5. A JSON-schema or grammar envelope (`{anchor, new_code}`) is plausible but no verified number shows it helps small models; Aider found JSON-wrapped code worse.
6. Model: qwen2.5-coder 7B Q4_K_M is about 4.7 GB (estimate) plus KV cache, so keep context <= 8k; same prompts on CPU as fallback.
7. Not found: RepoGraph, CodeRAG, EditEval and Aider benchmark methodology were not fetched.

Recommended pipeline for N = 24-120 frames, cheapest first:

1. Depth Anything V2 Small + MobileSAM mask, once per still.
2. Split into 8-32 depth layers and inpaint disocclusions once (OpenCV Telea first, LaMa optional; LaMa not read).
3. Render each frame by warping the cached layers along a camera path: milliseconds per frame on CPU (estimate).
4. Render every Nth keyframe and fill the rest with RIFE (verify its memory) or FILM at 720p (4.5 GB peak).
5. Stream frames to disk or ffmpeg; 120 frames at 720p is about 330 MB raw (calculated), so never hold them all.
6. Assemble with an LGPL ffmpeg build or the user's system ffmpeg.

Label the result "pseudo-3D parallax"; it stretches on large camera moves and is not AnyAngle.
Refuse by default: video diffusion, Flash3D, Splatter Image, MINE, Marigold, Stable Virtual Camera, and any NC weights.

## 4. Memorization probing (`probe_memorization`)

| Paper | Finding |
|---|---|
| 2012.07805 Carlini (GPT-2 XL) | 600k samples, 1,800 reviewed, 604 memorized; perplexity / zlib ratio rank candidates; a lower bound |
| 2311.17035 Nasr | memorization = a verbatim >= 50-token match in a known corpus (suffix array); 3 weeks on a 176-core, 1.4 TB RAM machine |
| 2202.07646 Quantifying Memorization | extractable = greedy continuation reproduces the true suffix; rises log-linearly with size and duplication; full scan >30 GPU-years |
| 2310.16789 Min-K% Prob | WikiMIA average AUC 0.72 (k=20); weak to moderate signal |
| 2402.07841 Do MIAs work on LLMs | AUC mostly < 0.6, near random; earlier high numbers largely reflect distribution shift |
| 2112.03570 LiRA | 256 shadow models (~25 GPU-hours, estimate); do not implement; report TPR at low FPR |
| 2404.02936 Min-K%++ | WikiMIA average 78.3 vs 67.8; one forward pass but needs full-vocabulary logits; **paper CC BY-NC-SA, code licence unstated** |
| 2002.06716 WeightWatcher | spectral statistics valid only within an architecture family; alpha fits reliable roughly for 2-4 |

LLM.int8, GPTQ, AWQ, the k-quant docs and any memorization-vs-quantization paper were **not fetched; no claim made**.

Design: replace `reverse_training_data` (which returned hardcoded numbers) with `probe_memorization`.
Metrics: NLL/perplexity, Min-k% (k=20), Min-k%++, zlib ratio, reference-model ratio, and an exact-suffix test only when the true text is supplied.
Target a Q4_K_M GGUF 3B-7B (about 2-4.4 GB, estimate) at `n_ctx` <= 1024 with `logits_all`; CPU fallback; load a ~0.5-1B reference model only after freeing the target.
Never compare scores across quantizations. Refuse below about 200 members and 200 non-members matched on length and domain; report AUC with a bootstrap CI and TPR at 1% FPR.
Caveat wording: "Scores indicate relative likelihood only. They are not proof of training membership. Published results show near-chance AUC (<0.6) on single-epoch pretrained LLMs once distribution shift is controlled (2402.07841)."
Weight statistics are meaningful only after dequantizing; Frobenius/spectral norms are weak; power-law fits on quantized blocks are meaningless.

Not read: DIRTY/Dire, malware/obfuscation evaluations, MCP tool-poisoning papers (blog only).

Model verdict: LLM4Decompile-Ref 1.3B quantized (Q4-Q8 GGUF) fits 6 GB and CPU (estimate); 6.7B at Q4 is borderline. Nova only if the licence permits. No model here applies to JavaScript; use deterministic deobfuscation.

Threat-model checklist for the proxy:

- Treat all engine output (strings, symbols, decompiled text, JS, metadata) as hostile data. Wrap with provenance `{source, sha256, tool, trusted:false}` and preserve REA's `_meta.provenance.untrusted_content`. Delimiting alone is not a control.
- Strip control, zero-width and bidi characters; cap string lengths; flag long base64.
- Pin tool schemas by hash and version-lock, so tool output cannot change tool descriptions.
- Allowlist tools per task (the best measured defence), read-only by default; mutating, exec, network or file-write tools need human approval. Do not chain untrusted output into egress tools.
- Re-state the user task before untrusted results; use injection detectors as flags only (they cost large benign utility).
- Caps: bytes/tokens per call, calls per session, timeouts, maximum binary size, pagination.
- Never execute analysed samples. Run the engine isolated (no network, read-only, unprivileged, CPU/RAM/time limits, no env secrets, no host mounts); canonicalize paths into one workspace and do not follow symlinks.
- Do not rely on model guardrails; log every call with provenance.

## 6. Decisions this research implies

1. Do not ship the AnyAngle / video-diffusion path as a default; ship depth-based parallax.
2. Replace the fabricated `reverse_training_data` with `probe_memorization` or `not_available`.
3. Use the official `gguf` package, and dequantize with a clear label.
4. Make the coding path function-region based with deterministic localization and a syntax gate.
5. Every model download must show its licence at install time; block non-commercial weights unless the user opts in.
6. Measure, do not assume: RIFE's memory claim, HT Demucs and Depth Anything V2 Small peak VRAM, and Q4 7B plus KV cache must be measured on a 6 GB card before any claim goes into user-facing docs.
